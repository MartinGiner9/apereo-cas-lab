# CAS server workspace

This directory deliberately separates project-owned configuration from the generated Apereo CAS WAR overlay.

```text
cas-server/
├── config/       # versioned CAS configuration
├── services/     # versioned registered services
└── overlay/      # generated by CAS Initializr; not versioned
```

## Why the overlay is generated

The official CAS overlay template is generated from CAS Initializr and changes alongside CAS itself. Forking or manually copying that repository into this lab would create noisy diffs and make upgrades harder to reason about.

Instead, the lab pins a CAS version and generates the overlay using the official Initializr API. The files we actually own remain small and explicit.

## Generate it

Linux/macOS:

```bash
../../scripts/bootstrap-cas.sh
```

From the repository root:

```bash
./scripts/bootstrap-cas.sh
```

Windows PowerShell:

```powershell
./scripts/bootstrap-cas.ps1
```

## Current modules

The first runnable milestone will require:

- JDBC support for PostgreSQL authentication;
- JSON service registry support;
- the PostgreSQL JDBC driver.

Do not add CAS modules pre-emptively. Each module increases dependency surface, startup complexity and upgrade/security maintenance.
